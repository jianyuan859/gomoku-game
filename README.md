# Gomoku 五子棋小游戏

纯前端实现的双人五子棋，使用原生 HTML + CSS + JavaScript 编写，无需任何框架与后端服务，打开网页即可游玩。

## 功能说明

- 双人同屏轮流落子，黑棋先行
- 自动检测横、竖、斜四个方向的五子连珠，实时判定胜负
- 支持一键重置对局，重新开始
- 棋盘与棋子使用纯 CSS 绘制，无图片依赖，体积轻量

## 技术栈

- HTML5
- CSS3
- 原生 JavaScript（ES6）


## 实现要点

- 使用二维数组维护棋盘状态，15 × 15 交叉点
- 落子后以当前落子点为中心，向四个方向双向延伸统计同色连子数，达到 5 即判胜
- 每次落子后重绘棋盘，保证状态与界面一致
